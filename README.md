# Misi Ejaan 22 — Permainan Digital Tahun 1

Permainan pembelajaran Bahasa Melayu untuk membantu murid menguasai kosa kata Ejaan 22.

## Kandungan
- Nama murid
- 10 soalan
- 3 pilihan jawapan
- Sistem markah
- Maklum balas betul/salah
- Keputusan akhir
- Reka bentuk kartun responsif
- Sesuai untuk telefon, tablet dan komputer
- Boleh diterbitkan menggunakan GitHub Pages

## Cara guna secara tempatan
Buka `index.html` menggunakan pelayar web.

## Cara terbitkan di GitHub Pages
1. Cipta satu repository baharu di GitHub.
2. Muat naik `index.html`, `style.css`, `script.js` dan folder `assets`.
3. Pergi ke **Settings → Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Tekan **Save**.
7. GitHub akan memberikan pautan permainan selepas proses penerbitan selesai.

## Nota guru
Soalan dan pilihan jawapan boleh diubah dalam fail `script.js` pada bahagian `const questions = [...]`.
